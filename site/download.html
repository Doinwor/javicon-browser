Что нужно для установки

Windows

  1. Скачайте Javicon Browser - JAR (для любой версии) или EXE-сборку (Windows).
  2. Для JAR убедитесь, что установлена Java 17+ (java -version).
  3. Запустите: java -jar JaviconBrowser-<версия>.jar
  4. Для EXE — просто запустите JaviconBrowser.exe (Java уже внутри).

Linux / macOS

  1. Скачайте jar-файл соответствующей версии.
  2. Выполните: java -jar javicon-browser.jar
  3. Либо соберите из исходного кода: mvn clean package
