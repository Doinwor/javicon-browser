Что это такое?

Javicon Browser — это самостоятельное приложение на Java, которое выглядит как Internet Explorer середины 90-х, но внутри использует JavaFX WebView (Chromium). Полная поддержка HTML5, CSS3 и ES6 в ретро-обёртке.

Актуальная версия

Версия Платформа Требования
Javicon Browser 1.0.0 Windows / Linux / macOS Java JDK 17+

Архив всех версий (включая старые) — на странице Загрузить или в GitHub Releases.

Основные функции

  • Олдскульный интерфейс в стиле IE 5/6.
  • Современный движок Chromium (HTML5 / CSS3 / ES6).
  • История посещений с сохранением между сессиями.
  • Закладки с импортом и экспортом.
  • Полноценное окно настроек с вкладками.
  • Загрузка файлов и сохранение страниц.
