Что такое Javicon Browser?

Javicon — это слово, образованное от Java и icon (икона). Мы делаем лёгкий, ретро-стилизованный веб-браузер, который напоминает старые браузеры типа Netscape Navigator и Internet Explorer 5/6, но при этом полностью современный внутри.

Почему такой стиль?

Интернет конца 90-х имел свой шарм: серые панели, рельефные кнопки, статус-бар "Готово". Javicon Browser возвращает этот дух, не отказываясь от современных веб-стандартов.

Технические детали

Параметр Значение
Язык Java 17+
GUI Swing (окно) + JavaFX (WebView / Chromium)
Сборка Maven + Shade (fat JAR)
Настройки ~/.javicon/settings.properties
Лицензия MIT
