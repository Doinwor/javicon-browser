Функции Javicon Browser

• Базовые функции

  • Загрузка страниц по URL.
  • Навигация вперёд / назад с историей.
  • Обновление страницы.
  • Настраиваемая домашняя страница.
  • Адресная строка и отображение заголовка страницы.
  • Индикатор загрузки в строке состояния.

• Работа с закладками и историей

  • Закладки с сохранением между сессиями.
  • Импорт и экспорт закладок.
  • История посещений, сохраняемая на диск.
  • Восстановление последней сессии.

• Загрузки и сохранение

  • Загрузка файлов с выбором папки.
  • Сохранение страниц в HTML ("Сохранить как...").
  • Управление путём загрузок из настроек.

• Настройки

  • Окно настроек с вкладками в стиле IE 5/6.
  • Выбор темы, шрифта и размера панели инструментов.
  • Настройка прокси, кэша и JavaScript.
  • Смена поисковой системы.

• Олдскульный стиль

  • Классический интерфейс в духе Internet Explorer 5/6.
  • Системный Look-and-Feel Windows.
  • Рельефные кнопки и серая панель инструментов.
  • Статус-бар с надписью "Готово".
