Что такое Javicon Browser?

Javicon Browser — лёгкий веб-браузер на языке Java, стилизованный под интернет-браузеры 1990-х годов (Netscape Navigator, Internet Explorer 5/6). Внутри использует современный движок JavaFX WebView на основе Chromium, поэтому поддерживает HTML5, CSS3 и ES6.

Название

Название «Javicon» образовано от двух слов: Java (язык программирования, на котором написан браузер) и icon (икона, образ). Вместе — «Java-икона», символ ретро-браузера, созданного на Java.

Описание

Javicon Browser сочетает классический визуальный стиль середины 90-х с современным внутренним движком. Пользователь видит серые панели инструментов, рельефные кнопки, статус-бар «Готово» и шрифт Tahoma. При этом страницы рендерятся на полноценном Chromium. Девиз проекта: «внешне — вчера, внутри — сегодня».

Возможности

Олдскульный интерфейс

  • Интерфейс в стиле Internet Explorer 5/6: серая панель инструментов, рельефные кнопки, статус-бар «Готово».
  • Системный Look-and-Feel Windows, шрифт Tahoma 11.
  • Текстовые кнопки панели: «Назад», «Вперёд», «Обновить», «Домой», «Настройки», «Перейти», «Добавить», «Избранное».

Современный движок

  • Поддержка HTML5, CSS3 и ES6 благодаря встроенному Chromium. Масштабирование страниц.

Навигация, история, закладки

  • Кнопки «Назад / Вперёд / Обновить / Домой».
  • История посещений, сохраняемая между сессиями.
  • Восстановление последней сессии при запуске.
  • Закладки («Избранное») с импортом и экспортом.

Загрузки и настройки

  • Загрузка файлов и сохранение страниц в HTML.
  • Настройки: домашняя страница, поиск, тема, шрифт, папка загрузок, прокси, кэш, JavaScript.

Установка

Способ 1 — JAR (все платформы)

  1. Установите JDK 17.
  2. Скачайте jar с сайта или GitHub Releases.
  3. Запустите: java -jar JaviconBrowser-1.0.0.jar

Способ 2 — EXE (Windows)

  1. Скачайте zip-архив.
  2. Распакуйте и запустите JaviconBrowser.exe. Java уже внутри.

Способ 3 — Из исходников

git clone https://github.com/Doinwor/javicon-browser.git
cd javicon-browser
mvn clean package
java -jar target/javicon-browser.jar
